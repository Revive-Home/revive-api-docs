<Update label="June 24, 2026" description="dashboard-v2.9.1, api-v3.6.3, api-v3.6.2" tags={["dashboard","api"]}>

### Dashboard

**Fixed**

- Saving and redirecting continues even if adding a note fails, so you no longer get stuck partway through. ([#192](https://github.com/Revive-Home/revive-apps/pull/192))

### API

- Contact records in production now route to the correct owner. ([#192](https://github.com/Revive-Home/revive-apps/pull/192))

<Update label="June 19, 2026" description="api-v3.6.1, admin-v3.8.0, dashboard-v2.9.0, api-v3.6.0" tags={["dashboard","admin","api","platform"]}>

**Highlights:** Property details (home type, year built, bedrooms, bathrooms and square feet) now come from three data sources in order, so fewer fields are blank in both the Dashboard and Admin.

### Dashboard

**Improved**

- **Fewer missing property details:** Home type, year built, bedrooms, bathrooms and square feet use AnyProp first, then HouseCanary, then Estated for any missing field. This applies to Step 2 of intake and wherever these details appear. ([#112](https://github.com/Revive-Home/revive-apps/pull/112))

### Admin

**Improved**

- **Property details fill in from backup data sources:** Staff see more complete home type, year built, bedroom, bathroom and square footage data. Each missing field falls back from AnyProp to HouseCanary, then to Estated. ([#112](https://github.com/Revive-Home/revive-apps/pull/112))

### API

**Fixed**

- Requests to outside services are less likely to fail with "premature close" connection errors. ([#181](https://github.com/Revive-Home/revive-apps/pull/181))
- When loading opportunities fails, the problem is now logged and a clear server error is returned instead of failing silently. ([#181](https://github.com/Revive-Home/revive-apps/pull/181))

### Platform

**Improved**

- **More reliable preview environments:** Preview environment setup now retries network and API calls, so review apps fail less often. ([#181](https://github.com/Revive-Home/revive-apps/pull/181))

</Update>

<Update label="June 18, 2026" description="admin-v3.7.0, dashboard-v2.8.0, api-v3.5.0" tags={["dashboard","admin","api","platform"]}>

**Highlights:** Admin opportunities get an experimental Sales tab with valuation and equity verification, plus a new Comparables card with a map. The dashboard adds ZIP photo downloads and lets out-of-state visitors start the Getting Started flow.

### Dashboard

**New**

- **Download photos as a ZIP:** The photos window has a Download photos button that exports all photos as one ZIP file. ([#133](https://github.com/Revive-Home/revive-apps/pull/133), [#143](https://github.com/Revive-Home/revive-apps/pull/143))
- **Satellite view on report maps:** Revive AI report maps can switch between Map and Satellite views. Spacing is also tidier on mobile screens. ([#149](https://github.com/Revive-Home/revive-apps/pull/149))

**Improved**

- **Out-of-state addresses in Getting Started:** Visitors with non-California addresses are no longer turned away after entering an address. They can still get a Revive AI report through the research path. Sell, renovate, and flip are blocked at the help step. ([#147](https://github.com/Revive-Home/revive-apps/pull/147))
- **Shorter research path in Getting Started:** The research path drops two research-specific questions. Signed-in users go straight to completion, and others go to sign-up. ([#166](https://github.com/Revive-Home/revive-apps/pull/166))
- **Prefilled property details are kept:** Property details and coordinates from deep links are preserved in Getting Started. Values users already entered are not overwritten. The Property Details step always shows so users can confirm. ([#143](https://github.com/Revive-Home/revive-apps/pull/143))
- **Tracking IDs in the new intake:** The new intake's sign-in step and phone verification subtitle carry tracking IDs again, so ads and analytics tools can follow them. ([#163](https://github.com/Revive-Home/revive-apps/pull/163))

**Fixed**

- Searching Revive AI reports now runs on Enter or the search icon, and clearing the field restores the full list right away. ([#152](https://github.com/Revive-Home/revive-apps/pull/152), [#133](https://github.com/Revive-Home/revive-apps/pull/133))
- Scheduling a meeting in Getting Started accounts for time zones, and the success banner now updates reliably. ([#133](https://github.com/Revive-Home/revive-apps/pull/133))
- When MLS or report photos fail to load automatically, an error message now appears. ([#133](https://github.com/Revive-Home/revive-apps/pull/133), [#143](https://github.com/Revive-Home/revive-apps/pull/143))
- The renovation scope button only appears for rooms that have a condition score. ([#133](https://github.com/Revive-Home/revive-apps/pull/133), [#143](https://github.com/Revive-Home/revive-apps/pull/143))
- Getting Started renovation step titles now match the user's role, so agents see wording about "you" and others see client-focused wording. ([#157](https://github.com/Revive-Home/revive-apps/pull/157))
- Photo uploads in the Getting Started flow now save with the correct file type. ([#164](https://github.com/Revive-Home/revive-apps/pull/164), [#166](https://github.com/Revive-Home/revive-apps/pull/166))
- Hovering a similar home card no longer cuts off its shadow. ([#140](https://github.com/Revive-Home/revive-apps/pull/140))
- Sell360 transaction summary content no longer gets clipped on short screens. ([#144](https://github.com/Revive-Home/revive-apps/pull/144))
- Revive AI reports no longer crash when a listing is missing location, names, photos, or material prices. ([#150](https://github.com/Revive-Home/revive-apps/pull/150))
- Revive AI analysis no longer fails for some homes, including attached homes and condos with no lot size. ([#161](https://github.com/Revive-Home/revive-apps/pull/161))
- Revive AI comparables no longer show the same listing twice, thanks to better address matching. ([#167](https://github.com/Revive-Home/revive-apps/pull/167))

### Admin

**New**

- **Sales tab with valuation and equity verification:** Opportunities have an experimental Sales tab. It shows equity document status and history, plus As-Is, After Renovation, and Renovation Budget values. Underwriting status now syncs onto deals. ([#133](https://github.com/Revive-Home/revive-apps/pull/133), [#158](https://github.com/Revive-Home/revive-apps/pull/158))
- **Property photos on deal cards:** Deal cards show a property photo thumbnail. A Property Photos gallery with a full-size viewer opens without blocking the page. ([#158](https://github.com/Revive-Home/revive-apps/pull/158))
- **Comparables card with map:** Opportunities show a Comparables card with a map of nearby properties. Open it to see top and other comparables with photos, price, and close date. You can refresh, filter Quality or All, and switch Map or Satellite. ([#133](https://github.com/Revive-Home/revive-apps/pull/133), [#169](https://github.com/Revive-Home/revive-apps/pull/169))
- **Original verified end date on timeline cards:** Timeline cards compare the original and current verified end dates. When they differ, an Original badge shows how many days the date has slipped. ([#175](https://github.com/Revive-Home/revive-apps/pull/175))

**Improved**

- **More consistent AI custom item descriptions:** AI-written custom item descriptions now follow one template. The Apply button and copy-to-text-box only work for valid descriptions. ([#148](https://github.com/Revive-Home/revive-apps/pull/148))
- **Easier AI chat for custom items:** The AI chat prompt accepts multiple lines, and the chat scrolls to the latest message when it opens or updates. ([#148](https://github.com/Revive-Home/revive-apps/pull/148))
- **Refreshed Add New Custom Item window:** The Add New Custom Item window has new spacing, borders, and text styling for the description editor. It works the same way. ([#172](https://github.com/Revive-Home/revive-apps/pull/172))

**Fixed**

- Searching Revive AI reports in Admin now runs on Enter or the search icon, and clearing the field restores the full list. ([#152](https://github.com/Revive-Home/revive-apps/pull/152), [#133](https://github.com/Revive-Home/revive-apps/pull/133))
- Clicking the search box in Manage Contacts on an opportunity no longer closes the sidebar, so you can search and type. ([#142](https://github.com/Revive-Home/revive-apps/pull/142), [#133](https://github.com/Revive-Home/revive-apps/pull/133))
- Create RMA request is disabled until an owner's rep is assigned, with a tooltip explaining why, so RMAs no longer get stuck. ([#135](https://github.com/Revive-Home/revive-apps/pull/135), [#133](https://github.com/Revive-Home/revive-apps/pull/133))
- A scope item in the weekly update can't be marked Completed until progress is 100%, and a message explains why. ([#151](https://github.com/Revive-Home/revive-apps/pull/151), [#133](https://github.com/Revive-Home/revive-apps/pull/133))
- The success message after creating a deal now disappears after four seconds and can be closed, so it no longer hides page buttons. ([#145](https://github.com/Revive-Home/revive-apps/pull/145))
- Tooltips now wrap their text instead of cutting it off, such as the one on the disabled Add change order button. ([#146](https://github.com/Revive-Home/revive-apps/pull/146))
- A random "Unauthorized" error in the AI chat for custom items is gone. ([#148](https://github.com/Revive-Home/revive-apps/pull/148))
- The required documents window now opens and closes more reliably. ([#158](https://github.com/Revive-Home/revive-apps/pull/158))

### API

**Fixed**

- Contract creation fails less often and returns clearer error messages for support. ([#162](https://github.com/Revive-Home/revive-apps/pull/162))

### Platform

**Improved**

- **Updated API runtime environment:** The API now runs on an updated runtime environment. ([#137](https://github.com/Revive-Home/revive-apps/pull/137))

</Update>

<Update label="June 4, 2026" description="dashboard-v2.7.0, dashboard-v2.6.0, admin-v3.6.0, admin-v3.5.0, api-v3.4.0, api-v3.3.2" tags={["dashboard","mobile","admin","api"]}>

**Highlights:** Customers get a new estimate experience with Summary, Scope and Full views and PDF downloads, a Renovate to Stay proposal, and a new Revive AI loading screen. Admin adds a Change Order GPT assistant and subcontractor commitment tracking.

### Dashboard

**New**

- **New estimate views and PDF downloads:** View estimates as Summary, Scope or Full, with a searchable sidebar and grouped line items. Download any view as a PDF with the view type in the file name. Line items now show their contract type. ([#20](https://github.com/Revive-Home/revive-apps/pull/20), [#27](https://github.com/Revive-Home/revive-apps/pull/27), [#10](https://github.com/Revive-Home/revive-apps/pull/10))
- **Renovate to Stay proposal:** A new proposal covers the renovation plan, process, design presentation, RenoVision gallery and neighborhood condition, with before/after image comparison. On phones, only the after image shows. ([#21](https://github.com/Revive-Home/revive-apps/pull/21), [#73](https://github.com/Revive-Home/revive-apps/pull/73), [#10](https://github.com/Revive-Home/revive-apps/pull/10))
- **Revive AI loading screen:** Report generation now shows a full-screen map with live comparable pins, a progress sidebar and a completion chime. Comparables and media save in the background, so reports open faster. ([#50](https://github.com/Revive-Home/revive-apps/pull/50), [#94](https://github.com/Revive-Home/revive-apps/pull/94), [#96](https://github.com/Revive-Home/revive-apps/pull/96))

**Improved**

- **Estimate PDF header shows the total:** Scope and full PDFs now show the logo, address and estimate total in the header. Leftover formatting from pasted notes is removed, so descriptions look consistent. ([#105](https://github.com/Revive-Home/revive-apps/pull/105))
- **At least two comparables required for a report:** Report generation now stops with a clear error if fewer than two usable comparables are found, instead of producing a weak report. ([#94](https://github.com/Revive-Home/revive-apps/pull/94), [#96](https://github.com/Revive-Home/revive-apps/pull/96))
- **Condition badges on comparables:** Comparable cards show rating-based condition badges with a score instead of stars. Unavailable rooms are labeled "Coming soon", and the "Need photos" pill now lets you upload photos. ([#95](https://github.com/Revive-Home/revive-apps/pull/95), [#78](https://github.com/Revive-Home/revive-apps/pull/78), [#96](https://github.com/Revive-Home/revive-apps/pull/96))
- **Property details fill in automatically:** When you start from a link that skips the address step, property details such as bedrooms and square footage now load automatically. Fields stay locked while they load. ([#74](https://github.com/Revive-Home/revive-apps/pull/74))
- **More accurate project completion:** Project completion now weights progress by item cost, so percentages better reflect the work done. Estimates also include cost breakdowns by product. The progress form shows a loading state while sending. ([#115](https://github.com/Revive-Home/revive-apps/pull/115))
- **Clearer Sell360 proposals:** Sell360 cost lines are split into Program fee, Agent commission and Holding costs, with a tooltip on holding costs. Comparison views and PDFs also show a compact cash offer. ([#128](https://github.com/Revive-Home/revive-apps/pull/128))
- **Signup tracking for marketing:** Creating an account now sends a completion event to Google Tag in production, so marketing can track registrations. ([#126](https://github.com/Revive-Home/revive-apps/pull/126))

**Fixed**

- Saving edits to a Revive AI report no longer fails when the property has no current value. ([#88](https://github.com/Revive-Home/revive-apps/pull/88))
- The property analysis card no longer crashes when valuation data is incomplete. ([#91](https://github.com/Revive-Home/revive-apps/pull/91))
- Shared report links no longer break their preview images when some report data is missing. ([#89](https://github.com/Revive-Home/revive-apps/pull/89), [#92](https://github.com/Revive-Home/revive-apps/pull/92))
- Dollar amounts in report headers now show properly rounded values on mobile and desktop. ([#98](https://github.com/Revive-Home/revive-apps/pull/98), [#96](https://github.com/Revive-Home/revive-apps/pull/96))
- Broadcast messages no longer pop up on public pages. ([#83](https://github.com/Revive-Home/revive-apps/pull/83))
- Image render jobs no longer leave the screen stuck, and download is hidden for jobs that weren't created by a user. ([#10](https://github.com/Revive-Home/revive-apps/pull/10))
- Older estimates get their missing product grouping back, and sub-item pricing and totals calculate correctly. ([#27](https://github.com/Revive-Home/revive-apps/pull/27), [#20](https://github.com/Revive-Home/revive-apps/pull/20))

### Mobile

**Improved**

- **Better link handling on Apple devices:** Dashboard links on iPhones now open in the app or the browser more accurately, because the list of excluded paths is refined. ([#111](https://github.com/Revive-Home/revive-apps/pull/111))

### Admin

**New**

- **Change Order GPT for custom items:** Use an AI chat to write custom item descriptions. Attach project photos and videos, refine the draft with quoted feedback, and apply the description to the item in one click. ([#103](https://github.com/Revive-Home/revive-apps/pull/103), [#96](https://github.com/Revive-Home/revive-apps/pull/96))
- **Subcontractor commitments:** Contracts and RMAs can now record a subcontractor commitment amount. It appears in opportunities, finance views, project metrics and the activity feed, and the Create RMA modals validate it. ([#123](https://github.com/Revive-Home/revive-apps/pull/123), [#96](https://github.com/Revive-Home/revive-apps/pull/96))
- **Status page for third-party services:** A new status page shows the health of HubSpot, Firebase, ATTOM and RestB, refreshing every minute. Slack alerts post when a service's status changes. ([#108](https://github.com/Revive-Home/revive-apps/pull/108), [#96](https://github.com/Revive-Home/revive-apps/pull/96))
- **Revive AI report in Admin:** Admin now includes the latest Revive AI report, with comparables, activity logging and invite management. Pages move from /vision-ai to /revive-ai. ([#81](https://github.com/Revive-Home/revive-apps/pull/81), [#102](https://github.com/Revive-Home/revive-apps/pull/102))
- **Additional cost on global estimate options:** Add a flat "Additional cost" to global estimate options. It carries through recalculations, and the Cost field is disabled with a tooltip when it doesn't apply. ([#110](https://github.com/Revive-Home/revive-apps/pull/110), [#96](https://github.com/Revive-Home/revive-apps/pull/96))
- **PO sheet link on RMAs:** RMA pages and modals show a "View PO sheet (Total Material Cost)" link when a spec sheet exists. New RMAs also take the material total from the sheet and log it. ([#55](https://github.com/Revive-Home/revive-apps/pull/55), [#10](https://github.com/Revive-Home/revive-apps/pull/10))

**Improved**

- **Admin RenoVision images:** The RenoVision configurator now works in Admin and its modals. Admin views show only admin-generated images and jobs. ([#125](https://github.com/Revive-Home/revive-apps/pull/125))
- **Estimate PDFs use the right view and name:** Admin estimate PDFs now pick the summary, scope, full or preliminary view to match the estimate. File names use the opportunity address when available. ([#97](https://github.com/Revive-Home/revive-apps/pull/97))
- **Renovation updates select automatically:** A newly created renovation update is selected and shown right away. Update details load faster because images and contacts load together. ([#119](https://github.com/Revive-Home/revive-apps/pull/119))
- **Custom labels show as badges:** Custom labels now appear as compact badges next to project scope labels and task headers, and they wrap neatly on small screens. ([#69](https://github.com/Revive-Home/revive-apps/pull/69), [#10](https://github.com/Revive-Home/revive-apps/pull/10))
- **Owners rep "Select all" filter:** The owners rep filter now supports "Select all", and the choice is kept in the page URL. Resetting filters clears the default owner right away. ([#72](https://github.com/Revive-Home/revive-apps/pull/72))

**Fixed**

- Rush and Remove Rush actions now appear based on the RMA's status and rush state instead of the user's role. ([#72](https://github.com/Revive-Home/revive-apps/pull/72), [#10](https://github.com/Revive-Home/revive-apps/pull/10))
- Signed estimates can no longer be duplicated, because the duplicate button is disabled once an estimate is signed. Change orders can still be duplicated. ([#100](https://github.com/Revive-Home/revive-apps/pull/100), [#96](https://github.com/Revive-Home/revive-apps/pull/96))
- Estimate totals now apply the 25% labor adjustment correctly and round once at the end, and new custom items default to the factored pricing view. ([#120](https://github.com/Revive-Home/revive-apps/pull/120))

### API

**Improved**

- **Home Prep contractor on contracts:** For Home Prep deals, contracts and estimate documents now use the standard Home Prep contractor and sign with that contractor's primary contact. ([#113](https://github.com/Revive-Home/revive-apps/pull/113))

**Fixed**

- Deals now show the correct pipeline stage label, with a fallback when the stage can't be found. ([#77](https://github.com/Revive-Home/revive-apps/pull/77))
- Purchase Discount and Revive Services amounts in contracts now round to the cent. ([#82](https://github.com/Revive-Home/revive-apps/pull/82))
- Excluded product line items no longer appear in the contract pricing table when certain additional options are selected. ([#82](https://github.com/Revive-Home/revive-apps/pull/82))

</Update>
