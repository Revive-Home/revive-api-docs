<Update label="September 25, 2026" description="admin-v3.17.2, api-v3.15.1" tags={["admin","api"]}>

**Highlights:** Admin gets new Sales Pipeline, Sell 360, Flip 360, and Renovate to Sell pages with deal sheets, plus new maps for active construction sites and home seller referrals. The MLS listings photo gallery now works.

### Admin

**New**

- **Sales Pipeline, Sell 360, Flip 360, and Renovate to Sell:** New pages and calculators cover the Sales Pipeline and the Sell 360, Flip 360, and Renovate to Sell options. Sales can model each path for a property in one place. ([#526](https://github.com/Revive-Home/revive-apps/pull/526))
- **Deal sheets connected to calculators:** Deal sheets now cover renovation budgets, property details, offer breakdowns, and selling options. Calculator results link to the deal information, so numbers stay consistent. ([#526](https://github.com/Revive-Home/revive-apps/pull/526))
- **Maps for construction sites and home seller referrals:** Two new map pages show active construction sites and home seller referrals. Teams can see where work and leads are located at a glance. ([#526](https://github.com/Revive-Home/revive-apps/pull/526))

**Improved**

- **Google Maps links and exterior photos on comparables:** Property addresses now open in Google Maps. Comparable listings can show saved exterior photos, with better fallbacks when an image is missing. ([#526](https://github.com/Revive-Home/revive-apps/pull/526))
- **Faster, clearer weekly updates:** Weekly updates now generate in the background and include a short status summary. Headings and formatting are updated so they are easier to read. ([#526](https://github.com/Revive-Home/revive-apps/pull/526))
- **Consistent Sales and Advisor tab order:** The Sales and Advisor tabs now appear in the same order across opportunity workflows, so they are easier to find. ([#526](https://github.com/Revive-Home/revive-apps/pull/526))
- **Better comparable details, documents, and signing errors:** Comparable property details are improved, document handling is smoother, and signing-session error messages are clearer. ([#526](https://github.com/Revive-Home/revive-apps/pull/526))
- **Photo gallery order and latest selection on MLS listings:** MLS listing galleries show photos in the order provided and leave out photos the listing provider removed. If you open another listing before the first finishes loading, the gallery shows your latest selection. ([#533](https://github.com/Revive-Home/revive-apps/pull/533))
- **Updated listing scores and score explanations:** Listing scores now include price-based adjustments for development opportunities and top out at 90 points. Score explanations describe how recommended products are chosen and how their badges relate to the score. ([#533](https://github.com/Revive-Home/revive-apps/pull/533))

**Fixed**

- Opening the photo gallery on MLS listings now works instead of failing, and it shows only photos, not PDFs or virtual tours. ([#533](https://github.com/Revive-Home/revive-apps/pull/533))
- Closing a photo gallery clears it, so photos from an earlier listing no longer reappear. ([#533](https://github.com/Revive-Home/revive-apps/pull/533))

### API

**Fixed**

- Requesting photos for a listing that can't be found now returns a clear "Listing not found" message. ([#533](https://github.com/Revive-Home/revive-apps/pull/533))

</Update>

<Update label="September 24, 2026" description="admin-v3.17.1, dashboard-v2.15.0" tags={["dashboard","admin","api"]}>

**Highlights:** Staff get a new MLS Listings page that scores listings for renovation and development opportunities. Customers can now customize bathroom renovations and generate AI designs, and payments now collect W-9 and ACH authorization documents.

### Dashboard

**New**

- **Bathroom renovation customization:** Customers can now customize bathrooms as well as kitchens. They pick a room, browse room-specific photos and real materials, and generate AI design images. Categories show only the options that apply. ([#186](https://github.com/Revive-Home/revive-apps/pull/186), [#467](https://github.com/Revive-Home/revive-apps/pull/467))

**Improved**

- **Edit Profile opens straight in edit mode:** Selecting Edit Profile in the Marketing Center now takes you directly to editing instead of the review step. ([#501](https://github.com/Revive-Home/revive-apps/pull/501), [#467](https://github.com/Revive-Home/revive-apps/pull/467))
- **Profile photo and logo save only when you click Save:** New profile photos and brokerage logos show as previews until you click Save, and Cancel restores your saved profile. The Marketing Center setup banners also have clearer wording. ([#482](https://github.com/Revive-Home/revive-apps/pull/482), [#467](https://github.com/Revive-Home/revive-apps/pull/467))
- **Skipped weekly updates count as progress in Project Log:** Skipped and punch-list weekly updates now appear as regular weekly-update entries in the Project Log. They count toward comment tracking and can qualify for approved progress milestones. ([#514](https://github.com/Revive-Home/revive-apps/pull/514))

**Fixed**

- Trying to render a bathroom design without choosing materials now shows a clear message. ([#186](https://github.com/Revive-Home/revive-apps/pull/186))
- Uploading a profile photo or brokerage logo no longer marks the marketing profile as edited before you change anything else. ([#501](https://github.com/Revive-Home/revive-apps/pull/501))
- The project home page keeps its loader until summary, activity and construction progress data are ready, so incomplete content no longer flickers on first load. ([#483](https://github.com/Revive-Home/revive-apps/pull/483), [#467](https://github.com/Revive-Home/revive-apps/pull/467))
- Selling-option buttons on reports open the right option, and renovation tabs appear only when renovation options are available. ([#520](https://github.com/Revive-Home/revive-apps/pull/520), [#467](https://github.com/Revive-Home/revive-apps/pull/467))

### Admin

**New**

- **MLS Listings page:** Review scored MLS listings with property details, photos and map links. Filter by renovation or development focus and minimum score, see score breakdowns, and flag a listing or dismiss it with a reason. ([#516](https://github.com/Revive-Home/revive-apps/pull/516), [#467](https://github.com/Revive-Home/revive-apps/pull/467))
- **W-9 and ACH documents on payments:** Payment forms collect a W-9 and, when needed, an ACH authorization (20 MB limit). You can view, download, replace or remove vendor documents. Payment emails and Slack notifications link to them. ([#493](https://github.com/Revive-Home/revive-apps/pull/493), [#467](https://github.com/Revive-Home/revive-apps/pull/467))
- **Groundbreaking photos in construction marketing:** Construction marketing can now use a project's groundbreaking photo, chosen once demolition is complete, in a new template. The project log notes when marketing collateral is delivered. ([#509](https://github.com/Revive-Home/revive-apps/pull/509), [#467](https://github.com/Revive-Home/revive-apps/pull/467))

**Improved**

- **Sold-status colors on the homeseller referral map:** Homeseller referral map markers now show sold-status categories and colors, so you can tell sold and unsold referrals apart at a glance. ([#493](https://github.com/Revive-Home/revive-apps/pull/493))
- **Weekly updates show who wrote them, with photos:** Weekly updates now show who created and published them, with names, avatars and dates. Renovation updates show photo thumbnails, attachment counts and a photo viewer. Pending updates show loading placeholders. ([#508](https://github.com/Revive-Home/revive-apps/pull/508), [#467](https://github.com/Revive-Home/revive-apps/pull/467))

**Fixed**

- Duplicate markers no longer appear on the homeseller referral map after it syncs. ([#493](https://github.com/Revive-Home/revive-apps/pull/493))
- Groundbreaking marketing collateral is no longer created before demolition is complete or when no suitable photo exists. ([#509](https://github.com/Revive-Home/revive-apps/pull/509))
- Copy link and Preview on a Revive AI report now use the dashboard address instead of the internal admin address, so people who receive a shared link can open the report. ([#479](https://github.com/Revive-Home/revive-apps/pull/479), [#520](https://github.com/Revive-Home/revive-apps/pull/520))

### API

**Improved**

- **Daily, safer listing status sync:** Listing status sync now runs daily at 2:00 AM Pacific instead of weekly. It checks that the property service is up first, stops after 500 straight failures, and only runs in production. ([#475](https://github.com/Revive-Home/revive-apps/pull/475), [#467](https://github.com/Revive-Home/revive-apps/pull/467))

</Update>

<Update label="September 21, 2026" description="api-v3.15.0" tags={["dashboard","api","platform"]}>

**Highlights:** Construction marketing materials now generate automatically for eligible deals, with progress shown in the dashboard. The valuation endpoint also returns mortgage details, and the Homeseller Referral map colors deals by sold date.

### Dashboard

**New**

- **Automatic construction marketing materials:** Marketing materials are generated automatically each day for eligible production deals. Incomplete marketing profiles are flagged before generation, so you know what is missing. ([#466](https://github.com/Revive-Home/revive-apps/pull/466))
- **Exterior photos in marketing templates:** Marketing templates can use the exterior photo selected for the opportunity. When none is selected, they fall back to Street View if it is available. ([#466](https://github.com/Revive-Home/revive-apps/pull/466))

**Improved**

- **Progress shown while marketing materials are created:** After a marketing profile update, you see progress and then a completed or failed status. The project marketing drawer shows a loading state while materials are being created. ([#466](https://github.com/Revive-Home/revive-apps/pull/466))

**Fixed**

- Marketing material generation handles invalid images, failed downloads and cleanup more reliably. ([#466](https://github.com/Revive-Home/revive-apps/pull/466))

### API

**New**

- **Mortgage details on valuations:** The valuation endpoint now returns the mortgage for the address: loan amount, lender, rate, term, due date and equity, from HouseCanary. A separate pending flag shows when it is still loading. Results are cached for 30 days. ([#512](https://github.com/Revive-Home/revive-apps/pull/512))
- **Homeseller referral map colored by sold date:** Referral markers on the Homeseller map are grouped by sold date, and each group gets its own color. Sold dates sync from HubSpot, so older deals are easy to tell apart. ([#485](https://github.com/Revive-Home/revive-apps/pull/485))

**Fixed**

- Duplicate markers on the Homeseller referral map are removed, keeping the one that has a category. ([#485](https://github.com/Revive-Home/revive-apps/pull/485))

### Platform

**Improved**

- **Map syncs run in production only:** The Active Construction and Homeseller map syncs now run only in production. Other environments no longer change the live maps. ([#485](https://github.com/Revive-Home/revive-apps/pull/485))

</Update>

<Update label="September 12, 2026" description="api-v3.14.1, api-v3.14.0" tags={["api"]}>

**Highlights:** Deal listing status now comes from Revive's own property data instead of AnyProp, and listing agent details are sent to HubSpot. Phone number searches also find contacts in more formats.

### API

**New**

- **Listing agent details sync to HubSpot:** The listing agent's name, phone and email now appear in HubSpot with the deal's listing status. Missing agent details are handled consistently, so records no longer keep stale or partial values. ([#469](https://github.com/Revive-Home/revive-apps/pull/469))

**Improved**

- **Listing status comes from Revive's property data:** The deal listing-status sync now uses Revive's own property data instead of AnyProp. It pulls listing, sale and status details. It also reports clearly when that data is unavailable or not set up. ([#469](https://github.com/Revive-Home/revive-apps/pull/469))
- **Phone search finds contacts in any format:** Searching for a contact by phone number now works with national and international formats, and with valid extensions. If the first search finds nothing, a fallback match runs, so fewer contacts are missed. ([#472](https://github.com/Revive-Home/revive-apps/pull/472))

**Fixed**

- The listing sync no longer links a deal to the wrong property when the address is ambiguous, number-only, or only partly matches the house number or street name. ([#469](https://github.com/Revive-Home/revive-apps/pull/469))
- Resolving duplicate contacts or reactivating a contact now saves the correct phone number when verified phone information is available. ([#472](https://github.com/Revive-Home/revive-apps/pull/472))
- Free-form U.S. phone numbers and numbers with valid regional lengths are now formatted correctly, so they match the right HubSpot contact. ([#472](https://github.com/Revive-Home/revive-apps/pull/472))
- New content notification emails now use the updated HubSpot email template. ([#477](https://github.com/Revive-Home/revive-apps/pull/477))

</Update>

<Update label="September 10, 2026" description="api-v3.13.1, admin-v3.17.0, dashboard-v2.14.0, api-v3.13.0" tags={["dashboard","mobile","admin","api"]}>

**Highlights:** Marketing Center gets a guided profile setup, and outside vendor payments now require invoices. A new lean valuation endpoint returns just the ARV and market value, and production deals sync automatically to HouseCanary Portfolio Monitor.

### Dashboard

**New**

- **Guided Marketing Center onboarding:** Set up or edit your marketing profile step by step, with photo, brokerage logo, contact details and phone verification. When your profile changes, you can review, skip or regenerate marketing materials. ([#420](https://github.com/Revive-Home/revive-apps/pull/420))

**Improved**

- **Submit project opens the getting-started flow:** The Submit project button now opens the guided getting-started flow instead of the intake page. It shows only for non-admin agents whose report has no opportunity yet. ([#419](https://github.com/Revive-Home/revive-apps/pull/419))
- **Service providers see deals across all their contractors:** Users linked to several contractors can open any home that matches one of them. Their RMA contracts are combined without duplicates, and still load if one contractor request fails. ([#461](https://github.com/Revive-Home/revive-apps/pull/461))
- **Wider, easier-to-read pre-construction page:** The project header and tabs use more room on large screens. Team cards, activity items, assets and empty states have better text sizing and spacing. ([#443](https://github.com/Revive-Home/revive-apps/pull/443))
- **Cleaner custom scope item names:** Custom scope items no longer show the redundant word "Custom" in their names. Subcategories without a category also get a larger, darker heading. ([#442](https://github.com/Revive-Home/revive-apps/pull/442))
- **Account matching and duplicate account cleanup:** Sign-in matches users by verified account ID, and duplicate accounts can be resolved by choosing a primary one. Deactivated accounts are blocked with a message to contact support instead of being reactivated. ([#301](https://github.com/Revive-Home/revive-apps/pull/301))

**Fixed**

- Phone verification during marketing profile setup handles errors and retries better. ([#420](https://github.com/Revive-Home/revive-apps/pull/420))
- OTP sign-in errors now tell you whether the code failed verification or the service had a problem. ([#301](https://github.com/Revive-Home/revive-apps/pull/301))
- Partial contact updates no longer change the contact's website by accident. ([#301](https://github.com/Revive-Home/revive-apps/pull/301))
- Users no longer get stuck in a sign-in loop caused by oversized saved session data. ([#447](https://github.com/Revive-Home/revive-apps/pull/447))

### Mobile

**Fixed**

- Logged-out users can open estimate and change-order approval screens again, and check promo and referral codes without signing in. ([#439](https://github.com/Revive-Home/revive-apps/pull/439))

### Admin

**New**

- **Edit paid dates on OV payments and RMAs:** Authorized admins can change the paid date from a payment's detail page using a calendar, with confirmation and a success or failure message. Already-paid records are limited by admin permissions. ([#463](https://github.com/Revive-Home/revive-apps/pull/463))
- **Required invoices on outside vendor payments:** Outside vendor payments need PDF or image invoices. Remaining-balance requests inherit earlier invoices, and links appear on the payment page and in Slack and Finance emails. ([#459](https://github.com/Revive-Home/revive-apps/pull/459), [#463](https://github.com/Revive-Home/revive-apps/pull/463))
- **ICO / CO scope option:** Outside vendor payments now offer a fixed "ICO / CO" scope option. ([#459](https://github.com/Revive-Home/revive-apps/pull/459))
- **Separate photo and document attachments:** Photos and documents are attached separately when publishing, with previews, PDF page counts and removable document chips. You can edit attachments inline and delete media with confirmation. ([#448](https://github.com/Revive-Home/revive-apps/pull/448))
- **Preview contractor documents from document cards:** Eligible contractor documents now have a preview action right on the card. The View details control is also clearer. ([#460](https://github.com/Revive-Home/revive-apps/pull/460))

**Improved**

- **Finance list and payment detail updates:** Finance entries sort from earliest to latest. Payment details show invoice files with download links and W9 status. The desktop RMA table no longer shows Amount requested. ([#463](https://github.com/Revive-Home/revive-apps/pull/463))

**Fixed**

- A prefilled vendor now shows correctly on outside vendor payment requests. ([#459](https://github.com/Revive-Home/revive-apps/pull/459))
- Completed non-production opportunities can be published without choosing a new start date. ([#446](https://github.com/Revive-Home/revive-apps/pull/446))
- Weekly updates can be created for a deal without picking a schedule date, and missing or invalid timeline dates no longer cause problems. ([#451](https://github.com/Revive-Home/revive-apps/pull/451))
- Marketing Center template pages load after sign-in, redirect to login when signed out, and show a retry option if loading fails. ([#439](https://github.com/Revive-Home/revive-apps/pull/439))

### API

**New**

- **Lean valuation endpoint for funnels:** A new endpoint returns only the ARV and market value, skipping the full report. Market value now comes from HouseCanary alone, so it no longer waits on slower scrapers. Funnels aren't switched over yet. ([#449](https://github.com/Revive-Home/revive-apps/pull/449), [#470](https://github.com/Revive-Home/revive-apps/pull/470))
- **Price and listing fields on Vision AI records in HubSpot:** Revive AI records in HubSpot now include ARV and as-is price per sqft, living area and listing status. Listing status is often unknown, and as-is price per sqft is blank on Neighborhood Analysis reports. ([#464](https://github.com/Revive-Home/revive-apps/pull/464))
- **Daily HouseCanary Portfolio Monitor sync:** Production deals are added to Portfolio Monitor each day and removed when marked Lost or Check Received. Deals that re-enter production are added back, with no duplicates. ([#415](https://github.com/Revive-Home/revive-apps/pull/415))
- **Homeseller Referrals map on Atlist:** Eligible Homeseller Referrals markers sync to the Atlist map daily, and stale markers are removed. Authenticated users can also trigger a sync manually. ([#453](https://github.com/Revive-Home/revive-apps/pull/453))

**Fixed**

- Looking up a brokerage with an invalid ID returns Company not found instead of a server error, which stops false critical alerts. ([#455](https://github.com/Revive-Home/revive-apps/pull/455))
- Comparable room types return an empty result instead of an error when RestB has no image data for a comparable. ([#456](https://github.com/Revive-Home/revive-apps/pull/456))
- Requesting a call from a Vision AI report no longer causes a server error when the signed-in user has no matching app record. ([#458](https://github.com/Revive-Home/revive-apps/pull/458))
- Estimates awaiting signature can now be deleted, including their non-draft contracts. ([#422](https://github.com/Revive-Home/revive-apps/pull/422))
- Signed PandaDoc documents missing contract details are skipped instead of causing a server error. ([#430](https://github.com/Revive-Home/revive-apps/pull/430))

### Action required

- Create four new properties on the Revive AI object in production HubSpot: arv_price_per_sqft, as_is_price_per_sqft, living_area and listing_status. They exist only in the sandbox, and the backfill for existing records hasn't been run yet. ([#464](https://github.com/Revive-Home/revive-apps/pull/464))

</Update>
