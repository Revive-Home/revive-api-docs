<Update label="October 6, 2026" description="api-v3.15.2" tags={["dashboard","mobile"]}>

**Highlights:** Opportunity details now fill in missing property information automatically when a full address is available. Pre-estimate links also now open in the browser instead of the mobile app.

### Dashboard

**Improved**

- **Missing property details fill in automatically:** When you open an opportunity with a complete address but missing property information, the missing details are filled in for you. Existing values are never overwritten. If the lookup fails, the opportunity loads as before. ([#548](https://github.com/Revive-Home/revive-apps/pull/548))

### Mobile

**Fixed**

- Pre-estimate links now open in the browser instead of the mobile app, so they no longer land in the wrong place. ([#540](https://github.com/Revive-Home/revive-apps/pull/540))

</Update>
